# 리더스클럽 6회차 — 준비 순서

## 파일

| 파일 | 역할 |
|---|---|
| `screen.html` | 빔 스크린에 띄우는 화면 |
| `index.html` | 참가자가 휴대폰으로 여는 화면 |
| `config.js` | **여기만 고치면 됩니다** — 키, 질문, 소개글 |
| `style.css` `db.js` | 공통. 건드릴 필요 없음 |
| `setup.sql` | Supabase 테이블 생성용 |

`magazine.jpg`(매거진 표지)와 `poster.jpg`(영화 포스터)를 같은 폴더에 넣으면
소개 화면에 들어갑니다. 없으면 빈 자리로 표시됩니다.

---

## 1. Supabase 준비 (10분)

1. supabase.com 에서 새 프로젝트 생성
2. 왼쪽 **SQL Editor** → `setup.sql` 내용 붙여넣고 **Run**
3. 왼쪽 **Settings → API** 에서 두 값을 복사
   - Project URL
   - `anon` `public` 키
4. `config.js` 상단 `supabaseUrl`, `supabaseAnonKey` 에 붙여넣기

키를 비워두면 **연습 모드**로 돌아갑니다. 디자인은 다 보이지만
휴대폰끼리 연결되지 않습니다.

## 2. 내용 채우기

`config.js` 에서 질문 2~6번 텍스트와 선택지, 매거진·영화 소개글을 채웁니다.

## 3. 올리기 (5분)

**Netlify Drop** — netlify.com/drop 에 폴더를 통째로 끌어다 놓으면 주소가 나옵니다.
계정 없이도 됩니다. 나온 주소가 참가자용 링크입니다.

- 참가자: `https://주소/`
- 빔 화면: `https://주소/screen.html`

참가자에겐 링크를 단축하거나 QR로 만들어 보내면 편합니다.

## 4. 리허설 (필수)

폰 두 대로 서로 다른 번호를 골라 제출해보고, 노트북의 `screen.html`
분포 화면에 즉시 반영되는지 확인하세요. 하단 표시가 **"실시간 연결됨"**
이어야 합니다.

---

## 당일 진행

- 빔 화면은 `→` 키 또는 하단 버튼으로 넘깁니다. `F11` 로 전체화면.
- 참가자는 번호와 이름을 고른 뒤 질문마다 선택 → 작성 → 제출.
- 제출한 답은 나중에 다시 열어 고칠 수 있습니다. 마지막에 고친 것이 남습니다.

## 끝난 뒤

`setup.sql` 맨 아래 주석의 SELECT 문을 SQL Editor 에서 실행하면
참가자별·질문별 답안이 표로 나옵니다. CSV 로 내려받아 후기 재료로 쓰세요.
